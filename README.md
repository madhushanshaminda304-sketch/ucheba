## 🚀 О проекте

Масштабный проект по воссозданию и технологической модернизации портала **Учёба.ру** — ведущей в РФ платформы для абитуриентов, школьников, студентов и специалистов. Платформа объединяет 8 уровней и форматов образования: от средних школ и лицеев до магистратуры, программ MBA и международного обучения.

### Ключевые возможности:

1. **Высшее образование и Бакалавриат**:
   - Каталог вузов с 7-факторной фильтрацией: по регионам, направлениям, проходному баллу, стоимости, общежитию и военной кафедре ([`/vuz`](/vuz)).
   - Профиль университета с программами обучения, кампусами и отзывами ([`/vuz/[id]`](/vuz/1)).
   - Национальный рейтинг вузов RAEX Top-100 ([`/vuz/rankings`](/vuz/rankings)).
   - Официальный классификатор специальностей РФ (ОКСО) с кодами направлений ([`/speciality`](/speciality)).
   - Детальный учебный план специальностей по 8 семестрам ([`/program/[id]`](/program/p1)).

2. **Колледжи и техникумы (СПО)**:
   - Каталог колледжей с фильтрами по среднему баллу аттестата и бюджетным местам ([`/colleges`](/colleges)).
   - Профиль колледжа со специальностями и условиями поступления ([`/colleges/[id]`](/colleges/col-1)).

3. **Школы, лицеи и гимназии**:
   - Каталог лучших лицеев и профильных школ России (Лицей НИУ ВШЭ, СУНЦ МГУ, Бауманская школа 1580 и др.) с рейтингами Департамента образования ([`/school`](/school)).
   - Профиль школы с профильными классами (IT-вертикаль, Инженерный, Медицинский) и правилами отбора ([`/school/[id]`](/school/school-hse-lyceum)).

4. **Непрерывное образование, Магистратура и MBA**:
   - Каталог курсов ДПО и IT-профессий с гарантией трудоустройства ([`/courses`](/courses)).
   - Программы магистратуры ведущих университетов и корпоративных лабораторий ([`/master`](/master)).
   - Бизнес-образование и MBA с международными аккредитациями (AACSB, AMBA, EQUIS) ([`/mba`](/mba)).
   - Каталог международного образования и зарубежных грантов/стипендий ([`/abroad`](/abroad)).

5. **Профориентация и Карьерный атлас**:
   - Атлас востребованных профессий с зарплатными вилками Junior / Middle / Senior ([`/prof`](/prof)).
   - Интерактивный психометрический тест на профориентацию из 10 вопросов ([`/proftest`](/proftest)).

6. **Подготовка к ЕГЭ / ОГЭ и Симулятор экзаменов**:
   - Онлайн-тренажёр заданий ФИПИ с автоматической проверкой ответов и пояснениями ([`/training`](/training)).
   - Онлайн-школа подготовки к экзаменам с гарантией 80+ баллов ([`/ege`](/ege)).
   - 10 предметных хабов со спецификацией ЕГЭ 2026: Математика, Русский язык, Информатика, Физика, Обществознание, Химия, Биология, История, Английский язык, Литература.

7. **Инструменты абитуриента**:
   - Симулятор расстановки приоритетов приёма по правилам РФ (до 5 вузов) с расчётом вероятности зачисления ([`/admission-tracker`](/admission-tracker)).
   - Сервис сопровождения поступления под ключ ([`/admission-support`](/admission-support)).
   - Календарь Дней открытых дверей с бесплатной онлайн-регистрацией ([`/events`](/events)).
   - Олимпиады школьников (ВсОШ и РСОШ I–III уровней) со льготами БВИ ([`/olympiads`](/olympiads)).
   - Матрица сравнения вузов до 4 позиций ([`/compare`](/compare)).
   - Избранное с сохранением в LocalStorage ([`/favorites`](/favorites)).

8. **Сервисы для партнёров и преподавателей**:
   - Кабинет репетитора с интерактивным конструктором задач и CRM учеников ([`/for-teachers`](/for-teachers)).
   - B2B портал для приёмных комиссий вузов и колледжей ([`/for-clients`](/for-clients)).

9. **UX / UI оптимизации**:
   - Полнотекстовый модальный поиск Command Palette (`⌘K` / `Ctrl+K`) по всем типам сущностей ([`SearchModal.tsx`](components/SearchModal.tsx)).
   - Глобальная система всплывающих уведомлений ([`Toast.tsx`](components/Toast.tsx)) без использования стандартных `alert()`.
   - Мобильная нижняя панель навигации ([`MobileNav.tsx`](components/MobileNav.tsx)) для быстрого управления одной рукой.
   - Единая модалка аутентификации ([`AuthModal.tsx`](components/AuthModal.tsx)) через SMS, Email, VK ID, Госуслуги и Яндекс ID.

## 🛠 Технологический стек

- **Фреймворк**: [Next.js 14](https://nextjs.org/) (App Router, Server Components + Static Site Generation)
- **Язык**: [TypeScript 5](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Клиентское состояние**: React Context API (`AppContext`) + LocalStorage
- **Сборка**: 53 полностью пререндеренные статические страницы

## 📦 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка и запуск продакшена
```bash
npm run build
npm start -- -p 3005
```
