## 🚀 О проекте

Независимый исследовательский проект по воссозданию структуры и сервисов образовательного портала **Учёба.ру**. Проект ставит во главу угла достоверность данных, отсутствие ложных обещаний зачисления, прозрачность источников и устойчивость локального рабочего пространства пользователя.

## ⚖️ Архитектура и честность данных

Все возможности разделены на три категории:

### 1. Полнофункциональные локальные модули (Fully Functional Local Features)
- **Гостевое рабочее пространство (`WorkspaceV2`)**:
  - Полностью локальное сохранение в `localStorage` без симуляции SMS-кодов или запроса паролей.
  - Настраиваемый профиль абитуриента с поддержкой строго валидированных баллов ЕГЭ (0–100) и сохранением выбранного региона/города.
  - Семантически корректная обработка: не заполненный балл — это `null` («нет данных»), а не `0`.
  - Версионированная схема хранения (`v2`) с автоматическим резервным копированием перед миграцией (`ucheba_workspace_backup_*`) и восстановлением при повреждении данных.
- **Типизированное избранное и сравнение (`SavedEntityRef`)**:
  - Раздельное хранение программ, вузов и колледжей по составным ключам `{type, id}`, исключающее коллизии идентификаторов.
  - Сохранение программы сохраняет именно выбранную программу, а не родительский вуз.
- **Интерактивный психометрический тест (`/proftest`)**:
  - 10-вопросный опросник профессиональных склонностей с вычислением профиля (реалистический, исследовательский, артистический и др.) и подбором рекомендованных профессий.
- **Тренажёр заданий ФИПИ (`/training`)**:
  - Интерактивная проверка числовых и текстовых ответов с объяснением решений.
- **Многофакторная фильтрация и поиск**:
  - Каталоги вузов, колледжей, программ и школ с фильтрацией по городам, направлениям, наличию общежития/военной кафедры.
  - Модальный поиск Command Palette (`⌘K` / `Ctrl+K`) с мгновенной навигацией по всем типам сущностей.

### 2. Исторические сопоставления и программы (Historical Data & Programs)
- **Сопоставление с проходными баллами 2024 года (`/admission-tracker`, `/profile`)**:
  - Проект **не рассчитывает «вероятность зачисления»** и **не гарантирует поступление**, так как конкурсная ситуация формируется новым пулом абитуриентов в текущем году.
  - Отображается строго историческое сопоставление с официальными приказами о зачислении 2024 года (ФИС ГИА и Приема).
  - При отсутствии введённых баллов выдаётся честный статус «Недостаточно данных для исторического сопоставления», а не завышенные шансы.
- **Учебные планы программ (`/program/[id]`)**:
  - Учебные планы отображаются исключительно для тех направлений, по которым есть проверенные данные (например, `09.03.04 Программная инженерия`).
  - Планы имеют явную маркировку статуса: `Официальный` или `Примерный / иллюстративный`.
  - Для программ без верифицированного плана не подставляются чужие IT-дисциплины; вместо этого выводится информативное сообщение и ссылка на официальный сайт приёмной комиссии.

### 3. Демонстрационные сценарии (Demo Forms & Scenarios)
- Локальные формы записи (сопровождение поступления на `/admission-support`, B2B-заявки на `/for-clients`, кабинет репетитора на `/for-teachers`, запись на мероприятия на `/events`, курсы на `/courses`):
  - **Не имитируют успешную отправку на несуществующий сервер** и **не обещают обратный звонок специалиста**.
  - Наглядно информируют пользователя о демонстрационном режиме интерфейса и предоставляют актуальные прямые контакты для связи (горячая линия `+7 (800) 200-84-42`, `priem@ucheba.ru`, `clients@ucheba.ru`).

## 📂 Модульная структура данных (`lib/data/`)

Данные проекта декомпозированы по предметным областям с обеспечением связности по первичным ID:

```
lib/data/
├── reference.ts          # Города, образовательные области, статьи, архетипы
├── institutions.ts       # Реестр вузов, колледжей и лицеев
├── programs.ts           # Программы бакалавриата, магистратуры, MBA, ДПО
├── careers.ts            # Профессии и специальности классификатора ОКСО
├── events.ts             # Дни открытых дверей, олимпиады школьников, рейтинги
├── interestQuestions.ts  # Вопросы профориентации и тренажёра ЕГЭ
├── lookup.ts             # Индексированный поиск сущностей по ID
├── integrity.ts          # Автоматический аудит целостности данных
└── index.ts              # Единый экспортирующий фасад
```

Для проверки связности и отсутствия битых ссылок:
```bash
npx -y tsx -e "import { runDataIntegrityAudit } from './lib/data/integrity'; const r = runDataIntegrityAudit(); if (!r.valid) { console.error(r.errors); process.exit(1); } console.log('Data valid:', r.counts);"
```

## 🛠 Технологический стек

- **Фреймворк**: [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation)
- **Язык**: [TypeScript 5](https://www.typescriptlang.org/) (строгая типизация, nullable поля, `0` != `null`)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Иконки**: [Lucide React](https://lucide.dev/)
- **Локальное состояние**: React Context (`AppContext`) + версионированный `WorkspaceV2` в `localStorage`
- **Сборка**: 53 полностью пререндеренные статические страницы

## 📦 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка и запуск продакшена
```bash
npm run build
npm start -- -p 3005
```

### 4. Проверка целостности данных
```bash
npx -y tsx -e "import { runDataIntegrityAudit } from './lib/data/integrity'; console.log(runDataIntegrityAudit());"
```
